# 项目经验

## Personal AI Knowledge Platform（本站）

技术栈：Next.js 15、React 19、TypeScript、SQLite、Docker、SSE。
配套：JWT 鉴权、GitHub Actions、内容层 Markdown 知识库。
展示 Developer Portfolio、Frontend Lab、安全登录与 AI Knowledge Assistant。
定位：AI 时代前端工程师个人技术平台。
Lighthouse 首页：性能 95、无障碍 96、最佳实践 96、SEO 100。

## ChatAI Multi-platform

晟为数科。uni-app / Vue3 / SSE。覆盖 H5、小程序、App。
负责多端 AI 对话核心页：流式输出接入与展示，按端处理收流差异；会话列表 / 历史分页；多端登录；微信 / 支付宝前端调起与结果处理。

## Enterprise WeCom SCRM

Vue3 + JavaScript（Web 运营后台）+ TypeScript（企微 App）+ Element Plus + Pinia + ECharts。
企微营销 SaaS：Web 管理后台 + 企微 App。
从 0 到 1 落地循环群发 / 朋友圈（周期配置、主子任务、字段规范化、过期状态收口）；虚拟列表优化员工预览；对照旧版重写并适配新后端联调。
覆盖群发、SOP、客户画像、员工小店；参与 AI 质检、客情分析、话术助手相关前端。

## 银行营销 H5 活动

HTML/CSS/JS · vw · Vant（按需）。
主动沉淀通用 H5 活动模板（页面骨架、切图配置、请求封装、跳转与字体适配），并输出移动端蓝湖协作开发规范。
以模板复用落地扬州、靖江、青岛、苏州、江都、盱眙等地 10+ 个银行营销活动；config / assets 配置化接入，请求层支持 Mock 联调。

## PRM · License & Channel Admin

晟为数科时期 ToB 后台（基于若依二次开发）。Vue2 + Vuex + Element-UI + ECharts。
扩展管理员 / 经销商 / 分销商多端：代理商、客户、订单、激活码 / 测试码、发货与进销存、授权证书；首页看板与角色菜单权限。

## KMS Console · Device Ops

晟为数科时期 ToB 后台。设备与镜像管理、KMS 激活及设备管控；支持 IP / 机器码检索，以及文件共享、剪切板、USB 等设备能力控制。

## ToC CMS · App Catalog Admin

晟为数科时期运营 CMS。应用列表与分类、安装包上传及静默安装 / 注册表配置；轮播、热门推荐、活动二维码、消息与问题反馈。
